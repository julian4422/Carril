# Carril backend

API REST (FastAPI + SQLAlchemy async + PostgreSQL) del gestor Kanban Carril.
Documentación completa en [`docs/`](docs/): [README](docs/README.md), [ARCHITECTURE](docs/ARCHITECTURE.md), [API](docs/API.md), [TESTING](docs/TESTING.md).

Arranque rápido (desde la raíz del repo): `docker compose up -d --build` y abrir http://localhost:8000/docs.
