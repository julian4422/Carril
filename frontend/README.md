# Carril · frontend

Cliente Angular 19 (standalone, signals, sin librerías de UI) del gestor Kanban Carril.

```bash
npm install
npm start          # http://localhost:4200, /api -> http://localhost:8000
```

Documentación completa en [`docs/`](docs/): [README](docs/README.md), [ARCHITECTURE](docs/ARCHITECTURE.md) y [TESTING](docs/TESTING.md).
