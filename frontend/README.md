# Carril · frontend

Cliente Angular 19 (standalone, signals, sin librerías de UI) del gestor Kanban Carril. Es una PWA instalable con arrastre táctil.

```bash
npm install
npm start          # http://localhost:4200, /api -> http://localhost:8000
```

Documentación completa en [`docs/`](docs/): [README](docs/README.md), [ARCHITECTURE](docs/ARCHITECTURE.md), [TESTING](docs/TESTING.md) y [MOBILE](docs/MOBILE.md) (PWA y arrastre táctil).
